🚀 Быстрый старт
1. Установка
# Клонирование репозитория
git clone <URL-адрес репозитория>
cd Playwright_python_efimova

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac

# Установка зависимостей
pip install -r requirements.txt
playwright install chromium
2. Настройка окружения
# Создайте .env файл на основе шаблона
cp .env.example .env

# Отредактируйте .env файл, указав актуальные данные:
# - BASE_URL (URL тестируемого приложения)
# - EMAIL (логин тестового пользователя)
# - PASSWORD (пароль)
3. Запуск тестов
# Все тесты
pytest

# Только smoke-тесты
pytest -m smoke

# Только E2E-тесты
pytest -m e2e

# Конкретный тест
pytest tests/test_auth.py::test_successful_login

# Запуск на другом окружении (переопределение BASE_URL)
BASE_URL=https://stage.topklik.online/ pytest
4. Просмотр Allure отчета локально
# Генерация и открытие отчета
allure serve allure-results

🏗️ Архитектура и технологии
Page Object Pattern
Инкапсуляция логики работы со страницами в отдельные классы для:

Переиспользования кода - локаторы и методы определены однажды
Легкости поддержки - изменения UI требуют правок только в одном месте
Читаемости тестов - тесты выглядят как бизнес-сценарии
Ключевые архитектурные решения
1. Абстрактный базовый класс
BasePage реализован как абстрактный класс (ABC) с обязательным методом navigate():

from abc import ABC, abstractmethod

class BasePage(ABC):
    @abstractmethod
    def navigate(self):
        """Каждая страница должна определить свою логику навигации"""
        pass
Преимущества:

Невозможно создать экземпляр базового класса напрямую
Гарантируется реализация обязательных методов в наследниках
Явный контракт наследования
2. Конфигурируемое окружение
Все параметры окружения вынесены в .env файл:

BASE_URL - адрес тестируемого приложения
EMAIL - логин тестового пользователя
PASSWORD - пароль
Преимущества:

Простое переключение между окружениями (dev/stage/prod)
Безопасность - конфиденциальные данные не в коде
Гибкость - можно переопределить через переменные окружения
